# Kickoff countdown

Reference: Figma file `OhrxqSyK9D1DtvUuulESvV`, frame `43:10124`, 390 × 844.

The screen uses the original crowd photo, Freiburg crest and dark status icons downloaded through Figma MCP. The Dortmund crest reuses the identical intro asset. Positions, yellow gradient, typography and copy follow the frame. Digital Numbers and Inter are local fonts from the Google Fonts repository; their OFL licenses are included in `public/fonts`.

The countdown reads the existing persisted session deadline and continues to advance automatically into the first half. Tapping the screen opens the existing lock-screen preview; demo next/previous/reset remain unchanged. Figma's prototype click jumps directly to the first half, while the app retains its functioning real countdown.

The screen shares the existing responsive Figma canvas, desktop viewport and persistent status bar. No hover styles are introduced.
